# Mini Dashboard Utenti (XHR)

Progetto didattico realizzato per esercitazione su AJAX e l'oggetto `XMLHttpRequest`.

## Tecnologie utilizzate
- HTML5
- CSS3
- JavaScript (Vanilla ES6, XMLHttpRequest)
- GitHub & Vercel per la pubblicazione

## Come avviare il progetto in locale
Trattandosi di chiamate AJAX, il file non va aperto direttamente tramite il protocollo `file://`.
Per eseguirlo:
1. Usare l'estensione **Live Server** di VS Code.
2. In alternativa, avviare un server locale da terminale:
   ```bash
   npx serve .
